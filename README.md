# manaos-bottons-app

App Android (Kotlin + Jetpack Compose) do stand de bottons do Armarinho Manaós: tablet do visitante.
Backend: Laravel em armarinhomanaos.com.br (API Sanctum). Documentação da API em `bottons-server/API.md` no projeto do servidor.

Build: `export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" && ./gradlew :app:assembleDebug`
